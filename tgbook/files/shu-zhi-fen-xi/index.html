数值分析

平台课, 计算核心课, 4学分

纸上得来终觉浅, 绝知此事要躬行.

  • 本课程曾经叫做数值计算与实验(一), 开设于第四学期, 现改名为数值分析, 相对应的, 数值计算与实验(二)现称数值代数.
  • 这门课程一直有邓卫兵老师任教, 偶尔还会有徐勤武老师和顾国勇老师等人上课.
  • 使用的教材是林成森的«数值计算方法», 由于不是按照课本顺序上课, 上下册均需要!!!
  • 上课的时候会使用祖传的ppt, 质量较低且有一些错误. 想要更清楚的了解, 可以去参考潘建瑜老师的讲义(下附链接)

https://math.ecnu.edu.cn/~jypan/Teaching/NA/main20210907.pdf

  • 课程分数组成是由平时+考试组成的. 平时的作业包括理论作业和上机实验, 考试包括期中, 期末和上机测试.
  • 理论作业基本上是教材上的习题
  • 上机实验则是一些经典的案例(基本上没变过), 要求编程实现(没有限制语言). 但是, 只完成代码是不足以应对的, 还需要完成万恶的数值报告(建议学习LaTeX).
  • 报告是坏文明, 建议合理使用AI工具(ChatGPT, Github Copilot等)来减少数值报告对身心的摧残, 上机题目以及报告实例已经包含在参考资料中, 可供参考.
  • 关于考试: 建议不只是背公式, 还需要知道公式的由来和作用, 这样才能更好的完成试题
  • 关于上机: 由于数学系机房的电脑过于破旧, 上机可以在断网的情况下使用自己的电脑, 且可以翻阅参考书, 极大地优化了上机=背书的坏文明.
