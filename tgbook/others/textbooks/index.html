课程教材一览

各学期课程的常用教材、讲义与参考书. 内容整理自《南数课程教材一览》.

大一上

  • 数学分析: 《数学分析》梅加强编著 第二版
  • 高等代数:
    • 朱富海老师班: 《高等代数与解析几何》朱富海、陈智奇编著
    • 其他班级: 《高等代数》丁南庆等编著
  • 解析几何: 《解析几何》尤承业编著
  • 程序与设计: 《C++ 程序设计》邵荣编著

注: 课程与考试内容几乎被 PPT 覆盖.

大一下

  • 数学分析: 《数学分析》梅加强编著 第二版

注: 2022 年起数分课程调整, 前半学期使用梅老师补充讲义, 级数部分被调整至大二上.

  • 高等代数:
    • 朱富海老师班: 《高等代数与解析几何》朱富海、陈智奇编著
    • 其他班级: 《高等代数》丁南庆等编著
  • 大学物理: 各班老师以 PPT 授课, 作业与考试内容多参考《普通物理学(第七版)习题分析与解答》孙迺疆、胡盘新主编.

大二上

  • 数学分析: 《数学分析》梅加强编著 第二版
  • 抽象代数:
    • 《近世代数》孙智伟编著
    • 陈柯老师曾使用: 《代数学引论》(第二版) 聂灵沼、丁石孙编著
  • 常微分方程: 程伟老师自编讲义, 每年实时更新. 作业与考试内容大量参考 GTM 182.

大二下

  • 数据库概论: 《数据库原理及应用与实践——基于 SQL Server 2019(第 4 版)》

注: 课程与考试内容几乎被 PPT 覆盖.

  • 数值分析: 《数值计算方法上册(第二版上下册)》林成森编著
  • 概率论基础: 《概率论基础(第三版)》李贤平编著
    • 宋玉林老师上课主要使用自编 PPT.
  • 复变函数: 《复分析基础》廖良文编著
    • 张高飞老师班选用 Stein 四部曲中的《复分析》, 其中第一册的《傅里叶分析》与之联系紧密, 为难得之名作, 强烈推荐阅读.
  • 离散数学: 《离散数学》屈婉玲编著 及 Fiddie 笔记
    • Fiddie 太强啦
  • 计算机图形学: 邵荣老师自编 PPT

大三上

  • 实变函数: 程伟、吕勇老师自编讲义(近期即将出版). 推荐教材有 Folland、周民强.
  • 偏微分方程: 《数学物理方程讲义》(第三版) 姜礼尚、陈亚浙等编著, 可取之处为零测集, 强烈推荐阅读 Evans
  • 拓扑学: 《基础拓扑学讲义》尤承业编著
  • 数值最优化: Nonlinear Programming by Dimitri
  • 数值代数: 《数值计算方法上册(第二版上下册)》林成森编著 及 张强老师自编讲义
  • 数理统计: 《应用数理统计(第三版)》孙荣恒编著
  • 应用随机过程: 代雄平老师自编讲义
  • Galois 理论: 《代数学引论》(第二版) 聂灵沼、丁石孙编著

大三下

  • 泛函分析: 秦理真老师自编讲义
  • 微分几何: 《微分几何》彭家贵编著
  • 运筹学: 《运筹学》孙麟平编著
  • 信息论: 《信息, 算法与编码》陆宏编著
  • 多元统计: 《应用多元统计分析》高惠璇编著
  • 时间序列分析: Time Series Analysis With Application by R J-D Cryrt, K-S Chan
  • PDE 数值解: 《偏微分方程的有限差分方法》张强编著

大四

In the wilderness, any direction is ahead.
